# notes/

每日打卡放这里。约定很简单：

## 命名

```
D<天>-<日期>.md      例：D01-2026-11-17.md
```

一天一个文件，别按主题拆。

## 每天写三件事

1. **今天做了什么** —— 有 commit / 部署 / 交易就贴链接（Sepolia / Lasna 的 reactscan 链接）
2. **卡在哪** —— 报错原文照抄，别转述。这是群里提问的草稿
3. **明天干什么** —— 一句话

## 模板

```markdown
# D01 · 2026-11-17

## 做了什么
-

## 卡住了
- 报错：

## 明天
-
```
